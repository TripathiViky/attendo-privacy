# Attendo — Privacy Policy

The published privacy policy for **Attendo**, an offline-first team attendance
tracker for Android (`com.vikytripathi01.attendo`).

Live at: <https://tripathiviky.github.io/attendo-privacy/>

Attendo collects no data, requests no Android permissions, and has no internet
access. This repository exists only to host the policy at a public URL, as
required by the Google Play Console.
